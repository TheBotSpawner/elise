# Architecture Decision Records

One file per decision, numbered sequentially and never renumbered:

```text
ADR-001-title.md
ADR-002-title.md
```

Recommended sections:

- **Status**: Proposed | Accepted | Superseded by ADR-XXX
- **Context**: the problem and the constraints behind it
- **Decision**: what was decided
- **Consequences**: trade-offs, and what becomes easier or harder

Do not edit an accepted ADR to change the decision. Write a new ADR that supersedes it.
